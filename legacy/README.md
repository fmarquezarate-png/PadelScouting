# Origen del proyecto

Archivos del dashboard del primer semestre 2026, guardados tal cual para no perder la referencia.

| Archivo | Qué es |
|---|---|
| `analisis-liga-padel.html` | El dashboard original, autocontenido. Referencia visual y funcional |
| `liga-2026-s1.txt` | La clasificación de los 6 meses, tal como se pega desde la web de la liga |
| `club-nivel.json` | Histórico del nivel del club de Fran y Cristian (fuente distinta a la liga) |

`liga-2026-s1.txt` es la carga inicial de la base de datos: 6 meses, 108 grupos, 81 parejas,
561 partidos, 0 descuadres entre las dos filas de cada enfrentamiento.
